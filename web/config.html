Download speed

Without a limit, a transcoded download is sent as fast as the GPU can encode it, often 20–60× realtime, which competes with every stream for the server's upload. Slowing the transfer also slows the encode: Jellyfin pauses ffmpeg once it gets ahead of the download (Dashboard → Playback → Transcoding → throttling).

The fastest one download is sent. 0 = no limit.
Shared by every download at once. 0 = no limit.
Their traffic never uses the internet upload. They still use a download slot.
Original-file downloads share the total limit. They need no slot.

Download slots

Each running download holds one hardware-encoder session until it finishes. 0 = no limit.
Extra downloads wait in the user's queue until a slot frees. 0 = no limit.
A download's whole output is written to the transcode folder until it finishes. A download is refused if it would leave less than this free.
